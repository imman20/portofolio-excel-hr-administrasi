# Checklist serah terima workbook

Saya memakai checklist ini untuk latihan serah terima, bukan bukti pengalaman kerja nyata.

- [ ] Saya mencatat nama file, versi, periode, tanggal acuan, penanggung jawab, dan tujuan penggunaan.
- [ ] Saya menjelaskan grain, kunci, satuan, sumber, batas tanggal, serta aturan KPI.
- [ ] Saya memisahkan Data dan Pembayaran sebagai input, Calculation dan Check_Pembayaran sebagai proses, serta Report sebagai output.
- [ ] Saya mempertahankan seluruh sumber dan daftar pengecualian; pembayaran tanpa tagihan dikenal tidak dipaksakan menjadi pendapatan atau pengurang saldo.
- [ ] Saya menghitung ulang, memeriksa error, dan merekonsiliasi detail serta total dengan CSV.
- [ ] Saya memeriksa sel kosong latihan, input yang boleh diubah, formula terkunci, dan password proteksi contoh yang didokumentasikan.
- [ ] Saya membedakan proteksi sheet dari enkripsi file dan pembatasan akses penyimpanan.
- [ ] Saya menyatakan aplikasi serta versi yang benar-benar diuji dan fitur yang masih manual.
- [ ] Saya mencantumkan cara membangun ulang, keterbatasan, tindakan saat gagal, dan pemeriksaan setelah perubahan.
- [ ] Saya menyimpan salinan sumber, salinan kerja, dan keluaran dengan nama yang tidak saling menimpa.
- [ ] Saya meminta penerima menelusuri satu angka dari Report ke sumber serta membaca satu pengecualian sebelum menerima file.
- [ ] Saya tidak menyatakan seluruh kasus bisnis bersih hanya karena rekonsiliasi matematis PASS.
